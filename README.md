# All Gear, No Go — Camping in Australia

A scrolling data story built for **FIT3179 Data Visualisation 2** (Monash University, Semester 2, 2026).

**Live site:** https://nisarg-bit.github.io/fit3179-dv2/

Australia owns more than 100,000 campervans and nearly 10,000 campgrounds to put them in. But each trip is getting shorter, and spending has stalled. The page follows that story through six sections and 17 interactive charts:

1. **The boom that was** — indexed growth, spending waterfall and a tile grid of state growth
2. **The turn** — spend per trip against nights per trip, and where the money is by site type
3. **Where the vans are** — postcode symbol map, remoteness heatmap, bar and lollipop charts
4. **Where the campgrounds are** — hexagon density map, binned-cell map and a per-head choropleth
5. **A territory of destinations** — ownership against camping nights, and a rank-change (bump) chart
6. **What they actually book** — accommodation waffle chart, age-group butterfly chart and a regional symbol map

## Audience

A general Australian reader with no data background. Every chart has a plain-language tip above it and a caption with the finding and source below it.

## Project structure

| Path | What it holds |
|---|---|
| `index.html` | The page: story text, key numbers, chart containers and the sources table |
| `css/style.css` | All styling (layout, typography, pull-stats, responsive rules) |
| `js/charts.js` | Loads each Vega-Lite spec with Vega-Embed and powers the map zoom controls |
| `specs/` | One Vega-Lite specification (`NN-name.vg.json`) per chart |
| `data/` | CSV, GeoJSON and TopoJSON files used by the charts |
| `fonts/` | Fraunces and DM Sans (SIL Open Font License) |
| `img/` | Hero artwork |
| `SOURCES.md` | Full list of data sources, licences and credits |
| `CAPTION-CREDITS.md` | The per-chart source line used in each caption |

## Run locally

No build step is needed. Serve the folder with any static server and open it in a browser:

```
python -m http.server 8000
```

then visit http://localhost:8000. The chart specifications load their data from `raw.githubusercontent.com`, so an internet connection is required (see `SOURCES.md`).

## Built with

- [Vega](https://vega.github.io/vega/), [Vega-Lite](https://vega.github.io/vega-lite/) and [Vega-Embed](https://github.com/vega/vega-embed) for every chart
- Plain HTML, CSS and a small amount of JavaScript
- Fraunces (headings) and DM Sans (text)

## Data

Caravan Industry Association of Australia (State of the Industry 2025), BITRE Road Vehicles Australia (via data.gov.au), OpenStreetMap contributors (ODbL), the Australian Bureau of Statistics and state boundaries from `rowanhogan/australian-states`. Details, links and the files each one feeds are in [SOURCES.md](SOURCES.md).
